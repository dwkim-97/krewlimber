# 멤버 목록과 채움 아이콘

멤버 카드를 가로로 긴 행이 위아래로 이어지는 목록으로 변경한다. 왼쪽에 아바타·이름·난이도·소개·활동 지역과 암장을, 오른쪽에 타이틀과 대표 업적을 표시한다. 배지들은 같은 열을 사용해 너비를 동일하게 맞춘다. 좁은 화면에서는 프로필 아래에 배지 열을 배치하고 가로 넘침을 방지한다.

기존 컴포넌트와 정보 팝업을 유지하며 목록은 ul/li로 표현한다. 별도 목록 컴포넌트나 새 데이터 계층을 만들지 않는다. 사용하지 않는 카드 전용 스타일은 제거한다. 이름 검색·난이도 필터·대표 업적 미선택 표시·복수 타이틀을 유지한다.

타이틀 아이콘과 획득 업적 메달은 내부에 색을 채운다. 명예의 전당 타이틀의 금색 강조와 대표 업적의 차분한 구분은 유지한다. 미획득 잠금 아이콘은 열쇠구멍을 보존하며 정보·검색·이동 아이콘에는 채움을 적용하지 않는다.

검증: 멤버 목록·검색·필터 및 기존 정보 팝업 테스트. 브라우저에서 데스크톱과 390px 모바일의 배지 너비 일치·가로 넘침·복수 타이틀을 확인한다. API와 타입은 변경하지 않는다.
