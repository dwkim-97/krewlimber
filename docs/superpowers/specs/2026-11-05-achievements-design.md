# 분기 타이틀과 업적

## 요구사항과 결정

가입 화면에 원본 로고를 사용하고, 영어 소제목·반복 안내·장식 문구를 줄인다. 참고 Pokrew의 타이틀 목록처럼 이름·보유자·선정 조건을 한 행에 표시하고 펼쳐 순위를 확인한다. 분기별 클라이밍 참여 횟수 1위(사용자 확정), 번개 개최 1위, 더클라임 빨강·핑크·보라 완등 1위를 선정한다. 양수 기록만 후보이며 공동 1위를 모두 표시한다.

내 정보의 업적은 첨부 이미지처럼 스크롤 가능한 목록으로 구성한다. 각 이름 밑에 짧은 조건과 진행 상태를 표시한다. 획득한 업적 하나를 대표로 선택하거나 해제할 수 있다. 멤버 이름 옆에는 현재 분기 타이틀들을, 이름 아래에는 대표 업적을 강조한다. 과거 분기 보유자는 명예의 전당의 분기 선택으로 확인한다.

## 방식

브라우저에만 가짜 데이터를 넣는 방법과 영구 저장되는 서버 기능을 비교했다. 사용자가 선택한 대표 업적을 새로고침과 멤버 목록에서 일관되게 확인하려면 서버 저장이 필요하므로 기존 SQLite/API를 확장한다. 정모·번개·완등 이벤트 입력 기능은 아직 없으므로 이번에는 운영진이 분기별 기록 숫자를 입력하고 서버가 순위와 누적 업적을 계산한다. 활동 이벤트 자동 수집은 이번 범위 밖이다.

## 데이터와 권한

- 활동 기록: 회원·분기·지표·비음수 정수. 클라이밍 참여, 번개 개최·참여, 더클라임 빨강·핑크·보라 완등의 6개 지표.
- 업적 정의: 고유 ID, 이름, 설명, 지표, 목표 수량. 기본 8개(색상별 50/100, 번개 개최/참여 50회)를 첫 DB 마이그레이션에서만 생성한다. 운영진이 추가·삭제할 수 있다.
- 업적 획득은 전체 분기의 해당 지표 누적이 목표 이상인지로 계산한다. 기록 정정으로 조건을 잃으면 대표 선택도 해제한다.
- 대표 업적: 회원별 하나 또는 없음. 본인의 획득 업적만 선택할 수 있다. 다른 회원의 상태나 진행도를 임의로 변경할 수 없다.
- 타이틀 조회·회원 장식 정보는 승인 회원만 접근한다. 활동 입력과 업적 정의 관리는 승인 관리자만 허용하고 변경 이력을 남긴다.
- 기존 계정·회원·성과 기록을 삭제하지 않는 추가 마이그레이션을 사용한다. 기존 성과 API는 보존하되 새 화면은 분기 타이틀을 사용한다.

## 테스트 데이터

하드코딩된 예시 계정은 명시적인 데모 시드 명령으로만 생성한다. 운영 모드와 일반 회원 DB에는 실행되지 않도록 막고, 기존 테스트 관리자와 세션은 유지한다. 테스트 계정·다양한 기록·대표 업적·과거 분기를 넣어 동률, 복수 타이틀, 업적 없음, 미선택과 여러 진행도를 확인한다.

## 검증

순위·동률·0건·분기 분리·비활성 회원 제외, 누적 달성 경계, 대표 업적 소유 검증·해제·기록 정정, 관리자 권한·입력 검증, 기존 DB 마이그레이션·삭제 후 재생성 방지, 데모 시드 보호와 멱등성을 테스트한다. PC·모바일에서 타이틀 펼침, 대표 선택 후 멤버 노출과 새로고침 유지, 가입 로고를 확인한다. 마지막에 /simplify와 Codex 리뷰(최대 2회)를 수행한다.
