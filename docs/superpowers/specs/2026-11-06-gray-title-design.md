# 회색 완등 타이틀

보라 타이틀의 표시 이름을 ‘보라 클래스’로 변경한다. 보라 기록·타이틀 ID는 유지한다. ‘세계관 최강자’는 해당 분기 [더클라임] 회색 완등 개수 1위에게 부여하며 기존 규칙대로 0건·미승인·정지 회원은 제외하고 동률은 공동 1위로 표시한다.

기존 분기 카운터에 필수 gray 필드를 추가해 기록 입력·검증·타이틀 계산·멤버 배지가 같은 지표를 사용한다. 회색 강조 색을 추가하고 기존 채움 아이콘을 사용한다. 별도 타이틀 수동 부여 기능이나 기본 회색 업적은 추가하지 않는다.

현재 DB의 지표 CHECK 제약에 회색이 없어 버전 6 마이그레이션으로 확장한다. 기존 활동 기록, 업적 정의와 정렬 순서, 대표 업적 선택, 회원·로그인·마켓 데이터는 보존한다. 사용자 삭제 기본 업적은 복원하지 않는다. 누락된 과거 회색 기록은 0으로 표시한다. 임시 데모의 회색 샘플을 추가하되 기존 프로필·비밀번호·대표 업적을 초기화하지 않는다.

## 추가 타이틀·업적

사용자 확인 기준: 번개 참여 1위 ‘번개 붙박이’, 포인트 순획득 1위 ‘포인트 채굴왕’, 포인트 실사용 1위 ‘마켓 큰손’을 추가한다. 타이틀은 한국 시간 분기별, 업적은 전체 기간 누적으로 계산한다.

순획득은 pointLedger의 grant 합계(지급−차감 정정)이며 환불은 획득으로 세지 않는다. 실사용은 취소되지 않은 교환(pending·completed)의 신청 당시 총액이며 교환 신청 시점 분기에 귀속한다. 나중에 취소해도 해당 사용액은 제외한다. 음수 순획득은 0으로 표시한다. 포인트 지표는 수동 활동 카운터로 입력하지 않는다.

기존 번개 참여 50회 업적을 유지하고 100회를 추가한다. 포인트 순획득과 실사용 각각 1,000·5,000·10,000P 업적을 기본으로 추가한다. 운영진은 기존 업적 관리에서 설명과 목표를 직접 수정할 수 있다. 기본 업적 도입은 기존 사용자 정의·삭제·대표 선택을 보존한다. 지급 정정·교환 취소로 조건을 잃으면 대표 선택을 해제하며 재달성해도 자동 재선택하지 않는다.
