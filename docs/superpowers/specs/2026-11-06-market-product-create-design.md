# 마켓 상품 등록 페이지

운영진이 마켓에서 바로 상품을 등록할 수 있도록 `/market/new`를 추가한다. 마켓 상단 등록 버튼은 승인된 관리자에게만 표시하며 페이지는 기존 `Protected access="admin"`과 관리자 상품 API로 보호한다.

## 접근 방식

기존 관리 화면으로 연결만 하면 별도 페이지가 없고, 등록 폼을 복제하면 검증과 저장 동작이 갈라진다. 기존 상품 폼을 공통 컴포넌트로 추출해 관리 화면의 수정 기능과 새 등록 페이지가 공유한다.

상품명·분류·포인트 가격·재고·이미지 주소·설명·판매 상태를 기존 계약 그대로 저장한다. 이미지가 없으면 `null`을 전송한다. 저장 성공 후 마켓으로 이동해 완료 메시지를 표시하며, 실패하면 입력을 보존하고 재시도할 수 있다. 취소는 마켓으로 이동한다. 저장 중 다른 화면으로 이동한 경우 늦은 완료 응답이 현재 화면을 바꾸지 않는다. 서버 API·DB·권한 역할은 추가하지 않는다.
