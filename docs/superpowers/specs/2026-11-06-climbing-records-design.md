# 클라이밍 방문 기록과 인스타그램

## 목적과 범위

사내 동호회 회원이 날짜·방문 암장·색상별 완등 수를 남기고 내 정보에서 프랜차이즈별 누적 실적을 확인한다. 참여·완등 기반 업적과 분기 칭호도 방문 기록을 근거로 계산한다. 인스타그램 프로필은 회원이 직접 입력하고 승인된 멤버 목록에만 링크로 공개한다.

## 선택한 방식

- 기존 React/Express/SQLite 구조를 유지한다. 브라우저 임시 저장은 기기 간 조회와 순위 집계에 적합하지 않다.
- 카카오맵 등록 업체명·place ID·주소를 검증한 서울/경기 암장 목록을 서버에서 제공한다. 공개 검색의 노출 제한으로 전수 검증이 안 된 범위는 전체 목록이라고 표현하지 않는다. 최신 전체 목록 갱신에는 공식 Kakao Local API 연결이 필요하며 키가 없는 현재 상태를 문서와 완료 보고에 명시한다. 키를 임의로 얻거나 외부 앱의 키를 사용하지 않는다.
- 별도 방문 기록 테이블과 색상별 완등 테이블을 사용한다. 프랜차이즈와 지점은 서버의 암장 목록으로 결정하며 클라이언트 임의 이름을 신뢰하지 않는다.
- 사용자가 새 방문 기록만으로 전환을 선택했다. 기존 참여/완등 수동값은 원본 보관하며 집계에서는 제외한다. 번개 개최·참여 및 포인트 집계는 유지한다.

## 회원 흐름

상단 `클라이밍 기록`과 내 정보 `기록` 탭에서 접근한다. 등록 페이지의 날짜는 한국 시간 오늘, 암장은 검색 다이얼로그에서 선택한다. 지점명·지역·주소로 검색하고 서울/경기를 필터링한다. 카카오맵 장소 링크로 업체를 확인할 수 있다.

선택한 프랜차이즈의 색상 순서는 사용자 첨부표를 따른다. 표에 없는 암장은 공통 색상 팔레트를 제공한다. 각 색상은 실제 색상 원과 수량 입력으로 표시한다. 커스텀 색상은 이름과 hex 색상 선택기 및 수량을 입력한다. 표는 사용자 참고이며 현재 공식 난이도 인증으로 표시하지 않는다.

확인된 동일 시설의 카카오맵 업체 ID 7개는 대표 업체 ID로 연결하고 원래 이름도 별칭 검색에 포함한다. 방문은 회원·날짜·대표 암장 ID당 한 건이다. 같은 날 다른 암장은 각각 참여 1회이며 동일 지점 중복 등록은 기존 기록 수정을 안내한다. 과거 날짜는 허용하고 미래 날짜·실재하지 않는 날짜는 거부한다. 완등 0개인 방문도 등록 가능하다. 본인 기록만 조회·수정·삭제 가능하며 삭제 후 복원할 수 없다. 삭제는 화면 확인을 거친다.

## 요약과 집계

내 정보 `기록` 탭은 방문 수·완등 수와 프랜차이즈별 색상 칩+숫자를 보여준다. 프랜차이즈를 클릭하면 방문한 지점별 색상 집계가 펼쳐진다. 독립 암장은 업체명으로 하나의 그룹이 된다. 흰색·회색·검정색도 구별할 수 있도록 테두리와 접근 가능한 색상 이름을 제공한다. 커스텀 색상은 이름·hex로 별도 집계한다. 방문 날짜순 목록에서 수정·삭제로 진입한다.

참여는 날짜+암장별 한 번이며 완등 수 합계와 별개다. 현재 더클라임 빨강·핑크·보라·회색 지표는 더클라임 지점의 해당 기본 색상만 집계한다. 다른 암장 색상과 커스텀 색상을 같은 난이도로 취급하지 않는다. 타이틀은 해당 기록 날짜가 속한 분기, 업적은 누적 전체 기간이다. 변경·삭제로 대표 업적 조건 미달 시 해제하고 재달성해도 자동 재선택하지 않는다. 기록만 있는 과거 분기도 명예의 전당 선택에 포함한다.

## 인스타그램

프로필에 required string `instagramUrl`을 추가하되 미입력은 빈 문자열로 저장한다. 입력 placeholder는 `클라이밍 인스타 계정`. `@계정` 또는 HTTPS instagram.com/www.instagram.com 프로필 주소를 허용하고 정규화한다. 게시물 경로·유사 도메인·자바스크립트·계정정보 포함 주소는 거부한다. 링크는 새 탭에서 안전하게 열린다.

## 데이터와 검증

DB v8은 기존 계정·암호·세션·프로필·포인트·번개 및 번개·포인트 대표 선택을 보존한다. 참여·완등 기반 대표 선택은 새 방문 기록이 없어 조건 미달이므로 전환 시 해제한다. 집계 전환은 원본 운영진 입력값을 삭제하지 않는다. 모든 새로운 타입 필드는 required 또는 의미상 nullable로 정의한다. 승인 회원만 기록과 암장 목록에 접근한다. 서버에서 날짜·수량·색상·업체 ID를 검증한다. 변경 및 감사 기록은 같은 트랜잭션으로 처리한다.

검증: 주소 정규화/거부, 본인 소유권, 미승인 차단, 날짜와 중복, 여러 암장/분기, 프랜차이즈 별도 집계, 커스텀 색상, 수정·삭제·대표 해제, DB 전환 보존, 키 없는 암장 목록의 검증 범위, 검색 다이얼로그 키보드·모바일 UI를 확인한다. 일반 PR을 생성하고 자동 검사를 확인한다.

## 구현자가 결정할 사항

새 의존성을 추가하지 않는다. 세부 간격과 색상 hex 값은 기존 테마에 맞춘다. 원본 첨부표 색상 순서는 보존한다. 사이트 문구와 구조는 간결하게 유지한다. 정적 목록은 실제 확인한 업체만 담고 누락 및 최신성 한계를 숨기지 않는다.
