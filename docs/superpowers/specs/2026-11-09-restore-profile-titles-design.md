# 프로필·타이틀·업적 복원

사용자가 기존 Supabase 배포본에서 제외된 인스타그램, 추가 타이틀·업적, 보라 칭호의 복원을 요청했다. 최신 main 1e872a9를 기준으로 하며 확인 시 미병합 PR은 없다.

기존 SQLite 구현 전체를 되돌리는 대신 현재 PostgreSQL 테이블·API·회원 카드에 필요한 기능만 이식한다. 인스타그램은 선택 입력이지만 응답 필드는 빈 문자열을 기본으로 항상 제공한다. 기존 클라이언트가 입력을 생략하면 저장된 값을 보존한다. 사용자명·@사용자명·정상 Instagram 프로필 URL을 정규화하고 외부 도메인·추적 쿼리·서비스 경로는 거부한다.

타이틀은 세계관 최강자(더클라임 회색 완등), 번개 붙박이(번개 참여), 포인트 채굴왕(순획득), 마켓 큰손(실사용)을 복원하고 보라 클래스 이름을 적용한다. 회색은 현재 공용 암장·난이도·방문 기록을 사용한다. 기존 여섯 수동 활동 지표는 그대로 유지하고, 포인트는 지급액에서 정정을 반영하며 사용은 취소 주문을 제외한다. 분기는 한국 시간 기준이다.

업적은 번개 참여 100회 및 포인트 획득·사용 각각 1,000·5,000·10,000P의 일곱 항목을 복원한다. 새 마이그레이션에서 한 번 추가하고 서버 시작 때 삭제한 업적을 재생성하지 않는다. 대표 선택과 회원 장식 정보에도 동일한 집계 함수를 사용한다.

카드형 회원 목록, 웹 업적 생성 제거, 암장 등록·레벨·지도는 유지한다. 운영 DB 마이그레이션과 배포는 실행하지 않고 검증 가능한 변경 파일을 일반 PR로 제출한다.
