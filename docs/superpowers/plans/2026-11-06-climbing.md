# Climbing records implementation plan

Goal: 암장 검색/지도, 난이도별 완등 기록, 레이팅 입력 집계를 로컬에서 제공한다.
Architecture: 공용 gyms/gymGrades, 개인 climbingVisits/visitSends. SQLite 로컬 미리보기와 PostgreSQL 배포용 마이그레이션을 모두 지원한다. 지도 키는 VITE_KAKAO_MAP_KEY, SDK services 장소 검색을 사용하며 없으면 정직한 빈 상태와 지도 검색 링크를 제공한다.
Constraints: 배포·푸시·운영 DB 변경 없음. 색상별 V등급 환산 없음. 기존 업적/포인트 값 덮어쓰기 없음. 회원만 접근. 본인만 기록 변경.

- [x] API: 회원 암장/난이도 추가, 중복 방지, 본인 방문 CRUD 및 난이도-암장 일치 검증. 날짜·개수·권한·오류 원자성 통합 테스트.
- [x] UI: 암장 목록/검색/장소 추가, 카카오 지도 키 연동, 개인 기록 난이도별 +/- 빠른 입력·수정·삭제. 저장 실패 시 입력 보존.
- [x] 레이팅: 방문/완등/난이도별 집계 및 기존 획득 업적 입력. 공식 점수 null, 버전 unconfigured. 내 정보 및 홈 연결.
- [x] 로컬 전용 DB/미리보기 시작, 타입/린트/테스트/빌드 및 내부 브라우저 확인.

Review focus: 타인 기록 수정, 잘못된 난이도 연결, 중복 행/재전송, 미래·잘못된 날짜, SDK 키 없음/오류.
Ruling: 사용자가 질문 없이 임의 구현을 승인했으므로 추가 설계 승인 없이 직접 실행한다.

Scope update: 사용자 요청에 따라 공용 장소 ID 중복 방지, 등록 시 난이도 일괄 저장, 회원 댓글(본인 수정/삭제, 관리 권한 삭제)을 추가한다.

검증: 전체 137 tests / 33 files 통과. 타입 검사·린트·빌드·Node ESM function check 및 diff check 통과. 내부 브라우저에서 로컬 기록 저장(회색 10개), 지도 마커, 상세, 댓글 저장 확인. 리뷰 발견 사항(재시도409, 위치 연결, 난이도 순서, 타일 오탐, CSP)을 수정. 운영 DB 마이그레이션·푸시·배포 없음.
